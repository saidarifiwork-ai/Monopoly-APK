QUARTIERS MAROC 3D — PROTOTYPE WINDOWS
Plateau 3D fourni, adapté aux villes marocaines

1. Extrais tous les fichiers de cette archive.
2. Ouvre Quartiers-Maroc-3D-prototype.exe.
3. Connecte-toi à Internet, choisis ton prénom et crée ou rejoins un salon.
4. Caméra : flèches du clavier, clic droit et mouvement de souris, molette.
5. Clique sur une case pour afficher son nom et son prix en grand.
Pendant la partie, le plateau reste dégagé. « Menu / actions » ouvre les
options et le compteur FPS ; « Mode performance » réduit la définition 3D.
« Décor flou » améliore le décor mais peut réduire la fluidité.
Au début de la partie, la caméra regarde vers le centre depuis ton pion :
le coin du joueur est en bas et le plateau s’ouvre devant lui.
Le lancer et l’arrêt des dés ont lieu au centre ; le flou est facultatif.
Utilise « Voir tout le plateau » pour afficher la carte complète, puis
« Suivre mon pion » pour revenir à la vue rapprochée.
À ton tour, utilise le grand bouton pour lancer les dés. Le bouton voisin
permet d’acheter la case où tu arrives. Clique une ville que tu possèdes :
ce bouton devient « Construire » si les règles permettent une construction.
Les enchères, les offres, les hypothèques et le mode auto restent dans le menu.

Le serveur configuré est celui du site web et de l’APK. Les fonctions principales
sont en cours de test. Le programme est un prototype : les monuments des villes,
les cartes, plusieurs animations et la validation sur un PC Windows réel restent
à faire. Utilise de préférence un salon de test.

Pour revenir à l’accueil, utilise le bouton prévu : un robot prend le relais et
la session peut être reprise sur le même ordinateur.

Les modèles de la ville proviennent notamment de Kenney (CC0) ; leur attribution
figure dans KENNEY-ATTRIBUTION.txt.

Logiciel créé avec Godot Engine. Sa licence est fournie dans GODOT-LICENSE.txt.

Les pions voiture, bateau et personnage viennent des modèles fournis par le
joueur. Le plateau est crédité dans PLATEAU-LICENSE.txt. Le dé lisse actif est généré
pour le jeu ; le modèle de dé fourni précédemment reste crédité dans DE-LICENSE.txt.
